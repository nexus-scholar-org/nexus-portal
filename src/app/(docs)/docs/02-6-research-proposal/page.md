## Learning Objectives
By the end of this lesson, students will be able to:
1. **Apply** the Heilmeier Catechism as a proposal structure framework.
2. **Construct** a Logic Model tracing funding to real-world impact.
3. **Produce** SMART research objectives.
4. **Structure** a 5-section grant proposal (Significance, Innovation, Approach, Team, Budget).

---

## Key Concepts

### Concept 1: The Heilmeier Catechism
7 questions from DARPA director George Heilmeier that map directly to proposal sections. The proposal answers all 7. See script for full list.

### Concept 2: The Logic Model
Inputs → Activities → Outputs → Outcomes → Impact. Reviewers must be able to trace the causal chain from money to societal benefit.

### Concept 3: Standard Proposal Structure
Significance → Innovation → Approach → Team → Budget Justification. Each section maps to Heilmeier questions.

### Concept 4: SMART Objectives
Specific, Measurable, Achievable, Relevant, Time-bound. Vague objectives are the #1 rejection trigger.
