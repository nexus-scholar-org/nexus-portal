# Lesson Specification: Module 4.4
## Metadata
| Field | Value |
|:---|:---|
| **Module** | Module 4.4 |
| **Title** | Responding to Peer Review |
| **Estimated Duration** | 25 minutes |
| **Prerequisites** | Module 4.1 (Academic Writing) |

## Learning Objectives
1. **Construct** a point-by-point response letter with quoted comments, direct responses, and tracked changes.
2. **Apply** professional response strategies for common reviewer scenarios (insufficient data, disagreement on interpretation, prior work claims).
3. **Distinguish** between defensive and professional responses.
4. **Reframe** rejection as redirection and develop a revision-and-resubmit strategy.

## Sources
1. Annesley, T. M. (2011). *Top 10 Tips for Responding to Reviewer and Editor Comments*. Clinical Chemistry.
2. Noble, W. S. (2017). *Ten Simple Rules for Writing a Response to Reviewers*. PLoS Computational Biology.
