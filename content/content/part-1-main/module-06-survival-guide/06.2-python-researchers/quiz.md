### Q1 (Remember)
**[Multiple Choice]** Which of the following is the standard Python library used for tabular data manipulation (the "Excel on steroids")?
- A) Matplotlib
- B) Pandas
- C) TensorFlow
- D) Jupyter

<details><summary>Answer</summary>**B** — Pandas is the engine for loading, filtering, and manipulating data.</details>

### Q2 (Understand)
**[Multiple Choice]** According to the lesson, why is writing a Python script to clean data superior to doing it manually in Excel?
- A) Because Python is faster to type than Excel is to click.
- B) Because Python generates an explicit, reproducible "audit trail" of every change made to the raw data.
- C) Because journals do not accept Excel files.
- D) Because Excel cannot do math.

<details><summary>Answer</summary>**B** — Reproducibility is the primary reason to use code instead of point-and-click software.</details>

---

### Q3 (Apply)
**[Multiple Choice]** You need to rename 500 image files in a folder. What is the most efficient approach?
- A) Hire an undergraduate research assistant to rename them manually.
- B) Use an LLM to write a 10-line Python script that iterates through the folder and renames them automatically.
- C) Open each file and use "Save As..."
- D) Upload them to Google Drive and rename them there.

<details><summary>Answer</summary>**B** — Automation is Python's superpower in research.</details>

---

### Q4 (Analyze)
**[Short Answer]** How has the rise of Large Language Models (LLMs) changed the way researchers should approach learning Python?

<details><summary>Sample Answer</summary>Historically, learning Python meant spending weeks memorizing syntax. With LLMs, researchers no longer need to memorize syntax; they only need to understand the logic and how to clearly prompt the AI (e.g., "Write a pandas script to...").</details>

### Q5 (Evaluate)
**[Multiple Choice]** A colleague argues, "I only have 50 rows of data. Writing a Python script will take me 20 minutes, but doing it in Excel will take 5 minutes. I should use Excel." What is the strongest counter-argument based on this lesson?
- A) "You're right, always use whatever is fastest."
- B) "While Excel is faster today, if the reviewer asks you to re-do the analysis with 5 new patients next month, the Python script will take 1 second to re-run, while the Excel method will take another 5 minutes and risk human error."
- C) "Excel is a proprietary software and unethical to use."
- D) "Python makes the graphs look 3D."

<details><summary>Answer</summary>**B** — Code is an investment in future reproducibility and iteration.</details>
